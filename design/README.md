# Proposta de redesenho (mockups)

Estes ficheiros **não fazem parte da aplicação** — não são compilados, não
entram no bundle e não são cobertos pelos testes. São mockups de uma
proposta alternativa de interface, para discussão.

| Ficheiro | Ecrã |
|---|---|
| `Main.dc.html` | Painel inicial |
| `Escolha.dc.html` | Escolha entre responsável e subcontratado |
| `Formulario.dc.html` | Formulário com a fundamentação legal sempre visível |
| `Registo.dc.html` | Registo em vista de leitura (documento) |
| `Validador.dc.html` | Modo validador do DPO, com anotações |
| `DirecaoCompacta.dc.html` | Direção visual alternativa, densa e tabular |
| `canvas.json` | Disposição dos artboards no canvas |

Todos os dados apresentados são fictícios (CLAUDE.md §2.7).

O canvas publicado é gerado a partir destes ficheiros e não é versionado
(ver `.gitignore`).
