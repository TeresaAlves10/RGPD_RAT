Não tens a certeza?

Faz esta pergunta: se amanhã decidíssemos usar estes dados para outra coisa, podíamos fazê-lo sozinhos? Se sim, a equipa é responsável. Se tivesses de pedir autorização a quem nos entregou os dados, é subcontratado.
